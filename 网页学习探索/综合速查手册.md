## 1. jiaoyikecha.com（交易可查）

**会话三步**（必须，否则数据接口 403）：
```python
import requests
s = requests.Session()
s.headers.update({"User-Agent": UA, "Referer": "https://www.jiaoyikecha.com/www.jiaoyikecha.com"})
s.get("https://www.jiaoyikecha.com/www.jiaoyikecha.com", timeout=20)
r0 = s.post("https://www.jiaoyikecha.com/ajax/session.php?v=5f6760cc", timeout=20)
sid = r0.json()["cookie"]["PHPSESSID"]
s.cookies.set("PHPSESSID", sid, domain="www.jiaoyikecha.com", path="/")
# 之后任意数据端点：
d = s.post("https://www.jiaoyikecha.com/ajax/variety_position.php?v=5f6760cc",
           data={"variety": "螺纹钢", "code": "rb2701", "date": "2026-09-07"}, timeout=20).json()
# -> {"code":0,"data":{"buy":[{broker_id,broker,grade,buy,buy_chge,net_position}], "ss":[...], ...}}
```

## 2. openvlab.cn（OpenVLab 市场）

**全匿名 GET**，响应 `{"code":0,"result":...}`，需带浏览器 UA + Referer。

| 需求 | 端点 | 返回要点 |
|------|------|----------|
| 全市场波动率地图（重点） | `GET /api/ctamap-all?add_overseas=true` | 83 品种：atmv_current/atmv_percentile/atmv_1dchg/skew_current/skew_percentile/rv22/price/frontfwd_mom/carry/exp/expiry_date/sector/exchange/has_night_trading |
| 单标的数据 | `GET /api/dto/{code}` | headline/isDelayed/requiresAgreement/events/context；code 支持 EG、510050 |
| 按月曲面 | `GET /api/volatility-surface/{code}` | key=到期月；含 atmv/mktvol/forward/delta/希腊字母/OI/PDF |
| 交易所/板块 | `GET /api/exchange-info` `GET /api/sector-info` | 8 交易所 / 6 板块(EQ股指 MT金属 EN能化 AG农副 OI油脂 BK黑色) |
| 品种+到期月 | `GET /api/product-exps?add_overseas=true` | 83 条 |
| 价格-波动率时序 | `POST /api/price-volatility-series` | body `{codes:"EG"}`（字符串）；需额外权限才有数据 |

**注意**：`volatility-surface-yday` / `watchlist/*` 需登录；产品码用 `product`(如 EG_O) 或 `prodUnd`(EG) 二选一对齐两端点。与桌面端 Legend 同源，cfwtd 网关只走交易链路。

## 5. 与量化/装置数据层协同建议

1. **openvlab 已接入装置**（`openvlab_collector.py` 三端点 → monitor.db option_chains/行情）；本任务确认 83 品种含海外、可加 `add_overseas` 扩展
2. **jiaoyikecha 候选接入**：`all_varieties.php`(补品种表)、`daily_wr.php`(仓单，量化侧缺仓单源)、`hg.php`(支撑压力)、`broker_trend.php`/`net_position_list.php`(资金/净持仓)、`longhu_list.php`(龙虎榜)——全部匿名，按 §1 会话三步即可
3. **qhqqbk 作资源索引**：量化新增数据源时先查归档定位官方入口（如 CFTC COT 官方页面、LME 官方价格页已归档）
4. 抓取护栏沿用量化项目 scrapling 对标成果：浏览器头/B1、会话持久化/A4、限流退避/A5、解析健康探针/A1、文本表格提取/A3
5. 失败重试机制：requests 失败 → StealthyFetcher 浏览器渲染 → 仍失败则标记"网络环境不可达"归档备查（对应 parser_health 告警口径）
