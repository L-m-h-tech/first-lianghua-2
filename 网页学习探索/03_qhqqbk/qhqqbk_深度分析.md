## 一、站点更新说明

### 1.1 架构变更

| 项目 | 更新前（旧版） | 更新后（当前） |
|------|---------------|---------------|
| 数据来源 | `app-data.js`（外部JSON文件） | 数据内嵌于主页面 HTML 中 |
| `app-data.js` 路径 | `https://www.qhqqbk.com/app-data.js` | **已失效，返回 404** |
| 主页面大小 | 约 15-20KB | **约 65KB**（含全部站点数据） |
| 分类数量 | 8 个 | **8 个**（64 个站点，219 条链接） |
| 唯一外部链接 | 约 75 个唯一域名 | **约 75 个唯一域名** |

### 1.2 更新要点

- 原 `app-data.js` 路径（`https://www.qhqqbk.com/app-data.js`）已失效，返回 HTTP 404
- 站长将全站目录数据从外部 JS 文件迁移至主页面 HTML 内联嵌入
- 主页面体积从约 15-20KB 膨胀至约 **65KB**，但仍为纯静态页面，无需 JavaScript 渲染
- 页面分类导航（`categoryNav`/`categoryGrid`）仍由 JS 渲染，但数据源已内联
- 搜索/筛选功能保留，`emptyState` 无结果提示仍在

### 1.3 技术影响

- **正面**：无需额外请求 `app-data.js`，单次页面加载即可获取全部数据，减少请求次数
- **正面**：数据结构化程度依然很高，HTML 中的 JSON 数据仍可直接解析
- **负面**：页面体积增大，但对现代浏览器无显著影响
- **对爬虫影响**：无需修改爬虫逻辑，直接解析主页面 HTML 即可提取全部站点数据

## 六、scrapling 项目应用

### 6.1 应用场景

`scrapling` 的 `StealthyFetcher` 在本项目中的核心价值是绕过服务端 JS 挑战，具体应用场景：

| 目标站点 | 问题 | scrapling 解决方案 |
|---------|------|-------------------|
| 郑商所 czce.com.cn | HTTP 412 JS 挑战 | StealthyFetcher 自动执行 JS，返回 200 |
| 大商所 dce.com.cn | HTTP 412 JS 挑战 | 同上 |
| 伦敦金属交易所 LME | HTTP 403 封锁 | StealthyFetcher 模拟浏览器指纹绕过 |
| 涌益资讯 yongyizixun.com | SSL 证书错误 | StealthyFetcher 忽略证书验证 |

### 6.2 实测结果

- **郑商所**：5 个页面（官网 + 持仓排名 + 公告 + 仓单）全部从 412 → **200 成功归档**
- **大商所**：5 个页面（官网 + 持仓排名 + 公告 + 仓单）全部从 412 → **200 成功归档**
- **LME**：从 403 → **200 成功归档**（stealth 重试）
- 成功归档的文件带 `_stealth` 后缀，存放于 `HTML归档/<域名>/` 目录

### 6.3 使用示例

```python
from scrapling import StealthyFetcher

fetcher = StealthyFetcher()

# 绕过郑商所 412 JS 挑战
response = fetcher.fetch("https://www.czce.com.cn/cn/jysj/ccpm/H077003004index_1.htm")
print(response.status)  # 200
print(response.text[:500])  # 完整 HTML 内容

# 绕过大商所 412 JS 挑战
response = fetcher.fetch("http://www.dce.com.cn/dce/channel/list/176.html")
print(response.status)  # 200
```

### 6.4 注意事项

- StealthyFetcher 启动较慢（约 3-5 秒/请求），不适合高频采集
- 建议仅对 requests 返回 412/403 的站点使用 scrapling 重试
- 已在本项目中验证：219 个链接中，187 个通过普通 requests 成功，18 个通过 scrapling 重试成功，32 个为海外站点网络封锁（非技术可解）

## 八、技术结论

1. **qhqqbk.com 是纯导航站，自身无数据接口**，核心价值 = **全市场资源地图**（已完整解析 + 归档）。站点更新后数据从外部 JS 迁移至 HTML 内联，但结构化程度依然很高，解析逻辑无需大改。

2. **国内数据获取渠道按优先级排序**：
   - 第一梯队（直接可采集）：新浪行情、东方财富、生意社、AKShare
   - 第二梯队（直接可采集但需处理大页面）：上海有色、钢之家、卓创、隆众
   - 第三梯队（需 scrapling）：郑商所、大商所、LME
   - 第四梯队（需代理）：Bloomberg、Reuters、CME

3. **scrapling StealthyFetcher 的实战价值**：在本项目中成功解决了 CZCE/DCE 的 412 JS 挑战和 LME 的 403 封锁，是量化数据采集中不可或缺的反检测工具。

4. **海外数据的"软可访问"**：尽管 32 个海外链接无法直接访问，但 BEA（GDP/PCE）、美联储（FOMC）、CFTC（COT）、EIA（原油库存）、NOAA/ECMWF/WMO（天气数据）均可在国内直连，为宏观和天气因子研究提供了宝贵数据源。
