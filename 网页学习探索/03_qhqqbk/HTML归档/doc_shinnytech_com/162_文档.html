TqSdk 使用指南

PYTHON · 行情 · 交易 · 回测

TqSdk 是开源的 Python 量化交易开发包。
使用统一的 API 获取行情与历史数据，编写策略，进行回测、模拟和实盘交易。

本文档按“快速上手 → 常用功能与模块参考 → 进阶专题 → 产品与支持”的路径组织，方便按学习阶段和使用场景查阅。

十分钟快速入门 → 查阅 API 参考
Python 3.9+开源 Python SDK从本地模拟开始

选择你的起点

第一次接触 TqSdk，可以先了解它的能力，再运行第一个程序，之后按需查阅常用功能。

01 / INTRO 了解 TqSdk

了解开发包的主要能力、程序结构，以及行情、回测和交易如何配合。

阅读 TqSdk 介绍 → 02 / LEARN 跟着教程动手

运行第一个行情程序，理解更新循环，再尝试模拟交易和历史回测。

十分钟快速入门 → 03 / BUILD 使用常用功能

按任务学习行情、K 线、委托、目标持仓和回测，逐步构建自己的策略。

浏览使用指南 →

运行第一个程序后，建议继续阅读 策略程序结构 和 快期账户，再学习 合约, 行情和历史数据、账户与交易 与 交易辅助工具，最后按需进入进阶主题。

配合 AI 开发： 如果你使用 AI 编码工具，建议先给它加载 TqSdk Skills 压缩包与使用说明，再让它协助写代码或排错。使用说明页提供可直接复制的提示词和完整技能包。

按任务查找

获取行情与历史数据 →合约代码、实时行情、K 线与 Tick 数据。 下单与管理目标持仓 →委托状态、撤单、自动调仓与持仓管理。 运行策略回测 →选择历史区间、处理回测结束、查看回测结果。 寻找完整示例 →从基础功能到交易策略，按场景选择示例程序。 与 AI 一起开发 →给 AI 提供 TqSdk 技能包与项目上下文。 排查使用问题 →安装、登录、行情更新与模拟账户的常见疑问。

先理解这三个概念

  • TqApi 负责连接服务、维护数据并驱动策略。

  • 数据引用 会持续更新；先订阅，再在循环里读取，无需反复创建订阅。

  • wait_update() 推进数据、请求和后台任务；用 is_changing() 判断关心的数据是否变化。

继续阅读 策略程序结构，或先了解 TqSdk 介绍。
