## 一、OpenVlab Legend (openvlab.cn)

### 1.1 软件概况

OpenVlab Legend 是一款**跨平台（Windows/macOS）的专业期权/期货桌面终端**，定位为"专业、极简、跨平台的期权行情与风险分析工具"。

- 官网：https://openvlab.cn
- 客户端下载：https://openvlab.cn/legend （当前版本 v0.0.98）
- 使用教程中心：https://openvlab.cn/teaching
- 更新日志：https://openvlab.cn/changelog
- 技术栈线索：Web版使用 React 18 + TypeScript + Tailwind CSS + Vite 构建（基于 GitHub 上 Tradersway/openvLab 仓库）

### 1.2 账户体系与功能分级

| 账户类型 | 费用 | 主要功能 |
|---------|------|---------|
| 普通账户 | 免费 | 模拟/实盘交易、行情数据、基础波动率页面、期货详情、基础策略构建、策略回测模拟 |
| Pro 账户 | 免费（需申请） | 更高数据上限、直连高频行情、完整波动率曲面、历史隐含波动率叠加、增强策略回测、行权价持仓分析、希腊字母盈亏分解 |
| 机构版 | ¥10,000起 | 独立版本、无限自选股、最长历史回测范围 |

**注意：** 客户端每天可免费试用 10 分钟，可通过期货公司/合作大V渠道获得更长时间。Pro 支持积分兑换。

### 1.3 核心功能模块

1. **行情数据 (Market)** - 实时行情、国内外市场数据
2. **波动率分析 (Volatility Analysis)** - 波动率曲面可视化与分析
3. **策略构建 (Strategy Builder)** - 多区域界面，支持拖拽构建期权组合，分析 Greeks（Delta, Gamma, Theta, Vega, Rho），多维度盈亏分析
4. **期权排名 (Options Ranking)** - 期权流向排名
5. **实时异动 (Option Flow)** - 期权实时异动监控
6. **超级 GEX 面板** - 开发中
7. **数据 API 与 MCP 服务** - 开发中（重要！未来可能提供程序化接口）

### 1.4 自动化相关信息

#### 官方 API / MCP 服务
- 根据更新日志和下载页信息，**"数据 API 与 MCP 服务"** 目前标注为**开发中**。
- 这意味着 OpenVlab Legend 目前**尚未提供官方的编程接口**用于自动化操作。
- 未来可能提供标准化的数据 API 和 Model Context Protocol (MCP) 服务。

#### CDP (Chrome DevTools Protocol) 使用可能性
- OpenVlab Legend 的 Web 版使用 React 构建，但桌面客户端的技术栈（Electron / CEF / 原生）**尚未确认**。
- 如果桌面客户端基于 Electron 或 CEF，理论上可以通过 CDP 进行自动化控制。
- **当前没有找到任何关于 OpenVlab Legend 使用 CDP 的文档或社区讨论。**
- 建议：安装客户端后使用 Spy++ 或类似的窗口检查工具确认底层框架。

这些仓库主要是前端展示或测试工具，**没有找到自动化交易相关的项目**。

#### Bilibili 视频教程
- 官方在 Bilibili 上发布了一系列入门视频教程，涵盖实时行情、波动率曲面、策略构建、期权异动等模块。
- 建议通过 OpenVlab 教学中心（/teaching）访问完整教程列表。

### 1.5 自动化策略建议

由于 OpenVlab Legend 目前没有官方 API，自动化方案需要探索以下路径：

1. **等待官方 API/MCP 服务发布** - 这是最可靠的长期方案
2. **检查客户端底层框架** - 使用 Spy++、Accessibility Insights 等工具确认是否为 Electron/CEF 应用
3. **如果是 Electron/CEF** - 可尝试：
   - Chrome DevTools Protocol (CDP) 连接
   - Playwright 或 Puppeteer 连接已运行的实例
4. **如果是原生应用** - 可尝试：
   - UIA (UI Automation) / pywinauto
   - Win32 API (ctypes / pywin32)
5. **截屏 + OCR 方案** - 最通用但最不精确的后备方案

## 二、同花顺期货通 (fupage.10jqka.com.cn)

### 2.1 软件概况

同花顺期货通是同花顺（10jqka.com.cn）旗下的**期货交易终端**，属于同花顺生态系统的期货专用版本。

- 官网：https://fupage.10jqka.com.cn （返回 404，可能需要特定访问方式）
- 同花顺主站：https://www.10jqka.com.cn
- 同花顺下载中心：https://down.10jqka.com.cn

### 2.2 同花顺生态与相关产品

| 产品 | 说明 |
|------|------|
| 同花顺客户端 | 通用股票交易客户端 |
| 同花顺期货通 | 期货交易专用终端 |
| iFinD 金融终端 | 专业金融数据终端（含API接口，需付费订阅） |
| MiniQMT | 券商提供的官方量化交易接口 |

### 2.3 自动化方法总结

#### 方法一：easytrader - Win32 UI 模拟操作（最成熟方案）

**项目地址：** https://github.com/shidenggui/easytrader  
**星数：** 10.2k  
**许可证：** MIT  
**文档：** https://easytrader.readthedocs.io/

**核心原理：**
- 通过 **Win32 API** 操作同花顺客户端窗口和控件
- 模拟用户交互：查找窗口 -> 设置焦点 -> 发送按键/鼠标点击 -> 读取数据
- 属于 "UI模拟操作" 方案，直接操控客户端图形界面

**支持的平台：**
- 通用同花顺客户端
- 华泰客户端
- 国金客户端
- 银河客户端
- MiniQMT 官方量化接口
- 雪球组合跟踪
- JoinQuant / RiceQuant 模拟交易跟踪

**源码结构（easytrader/easytrader/）：**
```
clienttrader.py          - 基础 ClientTrader 类
universal_clienttrader.py - 通用同花顺客户端实现
gf_clienttrader.py       - 国金证券
ht_clienttrader.py       - 华泰证券
yh_clienttrader.py       - 银河证券
pop_dialog_handler.py    - 弹窗对话框处理
webtrader.py             - Web 交易
xqtrader.py              - 雪球交易
grid_strategies.py       - 网格策略
joinquant_follower.py    - JoinQuant 跟踪
ricequant_follower.py    - RiceQuant 跟踪
server.py                - 服务端组件
```

**基本用法示例（来自 Frytrader demo）：**
```python
from easytrader import clienttrader

trader = clienttrader.ClientTrader()
trader.connect('同花顺客户端路径')
trader.prepare(user='账号', password='密码')
info = trader.balance  # 获取资金状况
positions = trader.position  # 获取持仓
```

#### 方法二：Frytrader - 增强版 easytrader（含验证码处理）

**项目地址：** https://github.com/Fryt1/Frytrader  
**星数：** 21  
**核心改进：** 自动处理同花顺客户端验证码

**验证码处理流程：**
1. 智能检测包含"验证码"文字的窗口
2. 自动截取验证码图片，保存到 `captcha_debug/` 目录
3. 使用 Tesseract-OCR 引擎进行文字识别
4. 识别失败自动重试（最多5次，每次间隔1秒）
5. 可配置切换到手动输入模式

**技术细节：**
- 验证码图片控件 ID：`0x965`
- 验证码输入框控件 ID：`0x964`
- Tesseract OCR 配置包含：字符白名单、页面分割模式(psm)、OCR引擎模式(oem)
- 所有参数通过 `config.json` 配置

#### 方法三：MiniQMT - 官方量化接口（最稳定方案）

- 各大券商提供的官方量化交易接口
- 不需要模拟 UI 操作，直接通过 API 下单
- easytrader 已支持 MiniQMT 接入
- 需要券商账户开通量化交易权限

#### 方法四：iFinD API - 专业数据接口

- 同花顺旗下的专业金融数据终端
- 提供 Python 接口用于数据获取和策略回测
- 需要付费订阅
- 适合机构级数据需求

#### 方法五：UIA / pywinauto 方案

**说明：** 虽然没有找到专门针对同花顺期货通的 pywinauto 项目，但基于同花顺客户端的一般特性，可以采用以下方法：

```python
import pywinauto

# 连接到同花顺期货通窗口
app = pywinauto.Application(backend='uia')
app.connect(title='同花顺期货通')  # 或通过进程ID连接

# 获取主窗口
main_window = app.top_window()

# 查找控件并操作
# 注意：具体控件名称需要使用 Inspect.exe 或 Accessibility Insights 确认
```

**注意事项：**
- 同花顺客户端可能使用自定义控件，UIA 后端可能无法完全识别
- 建议同时尝试 `backend='win32'` 和 `backend='uia'`
- 使用 Spy++ 或 Accessibility Insights 检查控件树

### 2.4 同花顺客户端自动化关键技术点

1. **验证码处理** - 同花顺客户端会弹出验证码窗口，这是自动化的主要障碍
   - 方案A：使用 Frytrader 的 OCR 自动识别
   - 方案B：接入打码平台 API
   - 方案C：远程桌面 + 人工辅助

2. **弹窗处理** - 客户端经常弹出公告、风险提示等对话框
   - easytrader 的 `pop_dialog_handler.py` 已处理此类情况

3. **登录流程** - 需要处理账号密码输入、可能的短信验证码

4. **控件定位** - 同花顺使用自定义控件，需要：
   - 使用 Spy++ 获取控件类名和 ID
   - 使用 Accessibility Insights 检查 UIA 树
   - 可能需要基于坐标的点击作为后备

5. **窗口检测** - 需要确保客户端已启动并登录后再执行操作

## 三、对比总结

| 对比维度 | OpenVlab Legend | 同花顺期货通 |
|---------|----------------|------------|
| 软件定位 | 期权/期货分析研究终端 | 期货交易终端 |
