## 0. 给未来 Python 实盘自动化项目的核心结论（先看这节）

1. **交易客户端的一切关键数据（资金/持仓/委托/成交/合约列表）均可通过 Windows UIA 无障碍树直接读取**，不依赖 OCR/剪贴板——这是实测的最大发现（用 Python `uiautomation` 库实测 8 个交易页签全部可读），直接决定 Python 自动化架构选型。
2. **行情列表（FieldGrid 自绘网格）UIA 无文本**，仍走剪贴板/OCR（沿用采集装置现有三级方案）；但**交易窗口内的表格是标准 WPF DataGrid**（带 AutomationId），列头与数据行均 UIA 可读。
3. **交易窗口与行情窗口同进程同窗口**（`E:\同花顺期货通\bin\happ.exe` / 进程名 happ），交易为窗口内独立页签组（y≥1085），不是独立进程窗口。
4. 控件类型以 **WPF 自定义控件**为主（`Flight.Product.Controls.TabItemAnimation` 等），但元素语义（tab/button/radio/checkbox/textfield/combobox）标准，`uiautomation`/`pywinauto` 均可定位；**大量控件带 AutomationId**（§5.7/§5.9 全集），Python 可直接按 Id 定位，无需坐标。
5. **⚠️ 关键坑：下单按钮"买多/卖空/平仓"是 TextControl 而非 ButtonControl**——Python 自动化要用坐标点击或文本定位，不能按 Button 类型查找。
6. 模拟账户资金极小（可用 ≈101 元）——**真实下单验证必须用模拟账户**，本手册已记录下单面板全部控件，后续 Python 项目直接复用。
7. 行情主功能条 12 分类＋交易页签 8 组＋子页签，形成**多级 Tab 体系**，Python 自动化要分别定位（详见 §3、§4、§5）。
8. **键盘精灵＝搜索直达**：`Alt+W` 打开键盘精灵 → 输入代码（如 `jm2701`）→ Enter → 直接跳转该合约（§5.10）——解决"搜索待确认"盲区。
9. **本地配置＝离线金矿**（§7 扩充）：`users\<账号>\` 下有自选股(SelfStockV3.txt 188只)、完整热键表(MyHotKey.xml)、键盘交易快捷键(KeyBoradTrade.xml)、个人设置(personal_config.xml 老板键ALT+Z)、K线图表配置(ChartConfig.json)、结算数据库(Settlement.db 6表) 等——**Python 可离线读取大量配置与历史数据**。
10. **联网调研结论**：同花顺期货通无公开 CTP/下单 API；实盘生产最优路径是券商 CTP 直连（vnpy_ctp/openctp），客户端内操作只能 UI 自动化（详见《同花顺期货通_Python自动化调研报告.md》）。

### 6.1 登录（模拟账户）

### 6.2 下单（以焦煤 jm2701 为例）
