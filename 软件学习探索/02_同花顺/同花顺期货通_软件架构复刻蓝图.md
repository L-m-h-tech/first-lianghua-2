# 同花顺期货通 软件架构复刻蓝图

> 目标：理解同花顺期货通的软件架构到能**从零复刻一个类似交易终端**的程度。
> 基于逆向分析（2026-09-14）：413 DLL/5 数据库/295 JSON/101 日志 + 实际 UIA 实测 + 网络/日志/程序集分析。

## 1. 表现层（WPF 前端）

### 1.1 控件体系
**同花顺的自定义控件**不是标准 WPF 控件，而是 Flight/Product 系列：
- `Flight.Product.Controls.TabItemAnimation`：交易/行情页签（支持动画切换）
- `System.Windows.Controls.Primitives.DataGridColumnHeader`：标准 DataGrid 表头（可点击排序）
- `Flight.Product.Controls.DataGrid`（推断）：行情自绘网格（FieldGrid，UIA 无文本）
- `CefSharp.Wpf.Browser`：Chromium 内嵌网页（用于资讯/期权分析/登录验证页）

**复刻建议**：
- 标准 WPF TabControl 替代自定义 TabItemAnimation（保持功能一致）
- 行情网格用 **DataGrid + 虚拟化**（替代 FieldGrid，解决 UIA 不可读问题）
- 右键菜单用 WPF ContextMenu 标准实现

### 1.2 主题系统（ThemeStyle.xml 实测数据）
颜色令牌体系（暗色主题）：
| 令牌 | 色值 | 用途 |
|---|---|---|
| Brush.C1-C4 | #EEEFF0/#B4B6B8/#63656C/#19A0FF | 控件主色（白/灰/深灰/蓝） |
| Brush.F1-F4 | #1C1D21/#25262A/#323337/#434448 | 深色前景/背景分级 |
| Brush.L1-L4 | #323337/#434448/#1482CC/#19A0FF | 行情线条/连接色 |
| Brush.T1-T4 | #213B4C/#19567F/#1482CC/#19A0FF | 标题/工具栏渐变 |

### 1.3 多屏布局配置
- `MultiScreenProject.json`：多屏项目元数据（ID/名称/分辨率/分辨率比例）
- 每个窗口用 GUID 目录保存独立配置（图表/期权页/指标）
- `WindowState`: 0=全屏/1=正常/2=最小化

## 2. 行情层（Hevo 协议 + 自绘网格）

### 2.1 协议架构（逆向推断）
```
服务端 Hevo 推送服务器（9601/8602）
    │
    ├─ 订阅管理（sid: 8019，Calc/Stats/Supercalc/Udns 四通道）
    │   └─ channel_info.xml: <channel qsid="8019"/>
    ├─ 数据加密（Hevo.Sdk/NaCl/SSPXEncode64）
    └─ 心跳机制（QuoteRecvTimeout/QuoteSendTimeout）

客户端
    ├─ Hevo.Api.Quotes（行情接口）
    ├─ Hevo.Core（核心数据模型）
    ├─ Hevo.MqApi（消息队列）
    └─ Flight.Quote（行情展示逻辑）
```

### 2.2 行情数据流
```
Hevo推送 → 解密 → Flight.Quote处理 → 
  ├─ FieldGrid（自绘网格，UIA不可读，需OCR/剪贴板）
  ├─ K线引擎（MA/MACD/BOLL等）
  ├─ 数值面板（最新/涨跌/持仓/成交量）
  └─ 底部状态栏（三大指数）
```

### 2.3 自绘网格（FieldGrid）设计理解
- 同花顺的行情表格是**自定义绘制**（非标准 WPF DataGrid）
- UIA 层面只暴露 `System.Data.DataRowView`（文本内容被截断，不可读）
- 这是**性能优化**：自绘网格比标准控件快，适合高频刷新
- **复刻建议**：用标准 DataGrid（带 UIA 可读性）或 VirtualizingStackPanel + Canvas 自绘（复刻性能优势）

## 3. 交易层（多柜台 + 订单状态机）

### 3.1 柜台适配架构
```
Flight.TradeCenter（统一交易接口）
  ├─ Ctp.Core（CTP 6.7.11 → thosttraderapi_sm / thostmduserapi_se）
  ├─ KSTradeAPI（金仕达交易）
  ├─ Femas.dll（中金所 FEMAS）
  ├─ XOneWrap / KCC_API / ustptraderapiFM（其他柜台）
  └─ Flight.Sdk（接口抽象层）
```
**设计模式**：**策略模式**——Flight.TradeCenter 根据券商代码（MoNiSDK/YHqh/HuaTaiqh）选择柜台实现。

### 3.2 订单状态机（逆向 Flight.TradeCenter）
```
下单流程：
SubmitOrder → OnRspOrderInsert（委托回报）
              → OnRtnOrder（委托更新：排队中/部分成交/全部成交/已撤单/拒绝）
              → OnRtnTrade（成交回报）

状态流转：
  提交中(Submit) → 排队中(Pending) → 部分成交(PartFilled) → 已成交(Filled)
                 → 已撤单(Cancelled) → 拒绝(Rejected)
```

### 3.3 弹窗确认链（实测完整流程）
```
点击"买多" → 弹出 WindowControl「委托确认」480×330（独立顶层窗口）
  → 确定 → 风险提示（风险度>70%时）
  → 柜台结果（交易反馈条 TextControl，UIA可读）
```
**弹窗设计特点**：WPF WindowControl（非 Dialog），支持勾选"不再提示"（白名单记忆到个人配置）

## 4. 数据模型（可直接复刻）

### 4.1 核心实体关系图（ERD）
```
[Contract] 38966行 ── 代码/名称/执行价/到期日/标的/乘数/市场码
    ↓ 外键 VarietyCode
[Option] 80个标的映射 ── 标的名/期货代码/是否期货/市场码
    ↓ 外键 contractCode（主力）
[MainContract] 87个品种主力合约 ── contractCode + market
    ↓ 外键 AccountKey
[Settlement] 6表 ── AccountKey/Date/Content（资产/持仓明细/成交/平仓/银期）
    ↓ 外键 ParentOrderID
[CondiOrder] ── 条件单本地库 ── ConditionOrder(JSON) + ChildOrderIDs

[SelfStock] ── 用户自选（188只，UserStock格式）
[BlockTree] ── 板块树（102板块，BlockId→品种通配符）
[HotKey] ── 热键配置
[ChartConfig] ── K线图表配置
[PersonalConfig] ── 个人偏好
```

| 层 | 同花顺实现 | 复刻选型（推荐） |

## 7. 复刻优先级路线图

**⚡ 关键验证（2026-09-14 实测）：内置完整 CTP API 可复用**
- `thostmduserapi_se.dll`（3.0MB）：**Python ctypes 可加载**；内含 `CreateFtdcMdApi`/`CThostFtdcMdApi`/`CThostFtdcUserApi`/`ThostFtdcUserApiImplBase`（标准 CTP 6.x 官方符号）
- `thosttraderapi_sm.dll`（3.3MB）：CTP 交易 API（`CreateFtdcTraderApi` 等）
- `KSTradeAPI.dll`（3.5MB）：金仕达交易（`ReqOrderInsert`/`OnRtnOrder`/`OnRtnTrade`）
- **结论**：复刻行情/交易底层时，可直接用 `ctypes`/`vnpy_ctp` 对接内置 CTP DLL（或向券商申请 CTP 地址直连），**不必自己实现行情协议**——这是"复刻类似软件"最关键的地基。

**MVP（最小可用版本，2-4周）**：
- [ ] 界面框架：WPF主窗口 + 12功能条 + 8交易tab
- [ ] 行情浏览：期货列表 + 五档盘口 + K线图（用开源图表库）
- [ ] 交易下单：品种输入 + 手数/价格/买卖 + 确认弹窗
- [ ] 账户资金/持仓读取

**第二阶段（4-6周）**：
- [ ] 行情实时推送（CTP行情直连）
- [ ] 条件单完整实现
- [ ] 期权行情/下单
- [ ] 自选管理 + 板块管理

**第三阶段（6-8周）**：
- [ ] 智能交易（算法拆单/追单/定时拆单）
- [ ] 画线下单/止损开仓
- [ ] 多屏布局
- [ ] 结算对账

**第四阶段（8-12周）**：
- [ ] 数据模型完善（主力合约/期权映射/code.db完整迁移）
- [ ] 平台化（多柜台适配、配置化）
- [ ] 压力测试/优化
