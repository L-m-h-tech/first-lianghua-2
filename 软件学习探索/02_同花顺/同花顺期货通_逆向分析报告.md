# 同花顺期货通 逆向分析报告

> 逆向日期：2026-09-14 ｜ 目的：深入理解软件内部结构，为自动化交易项目做技术选型。
> 方法：安装目录勘察 + .NET 程序集字符串分析 + 数据库结构解析 + 日志/网络/守护进程分析（全部只读，不修改任何文件）。
> 结论先行：同花顺期货通 = **多柜台适配层（CTP/金仕达/FEMAS）+ Hevo 私有行情 + WPF 前端**；行情协议加密不可直接复用，但有**大量离线可读数据资产**（主力合约字典/期权映射/本地条件单/结算库）可支撑自动化策略。

## 1. 技术栈全景（逆向确定）

### 1.1 交易柜台接口（多券商适配层）
| DLL | 协议 | 确认依据 |
|---|---|---|
| `thosttraderapi_sm.dll` | **上期技术 CTP 交易 API** | 导出 `ReqAuthenticate`/`ReqOrderInsert`/`LoginRemark`/`ClientIP`/`OrderInsertError` |
| `thostmduserapi_se.dll` | **CTP 行情 API** | 导出 `ThostFtdcMdApi`/`TDExchangeOrderInsertError` |
| `KSTradeAPI.dll` | **金仕达(Kingstar)交易** | 导出 `ReqStkOrderInsert`/`ReqOrderInsert`/`OnRtnOrder`/`OnRtnTrade`/`ReqQryExecOrderVolume` |
| `KSMarketDataAPI.dll` | **金仕达行情** | `SubscribeMarketData`/`OnRspUserLogin` |
| `Femas.dll` | **中金所 FEMAS 交易** | `ReqOrderInsert`/`ReqOrderAction`/`ReqQuoteInsert`/`OnRtnOrder`/`OnRtnTrade` |
| `Ctp.Core.dll`/`XOneWrap`/`KCC_API`/`ustptraderapiFM` | 其他柜台封装 | 目录观察 |

> ⚠️ 逆向意义：软件登录的"期货公司下拉"即对应不同柜台 API；**交易底层走券商柜台协议（CTP 系是主流）**。若券商开放 CTP 直连，可绕开客户端走 vnpy_ctp；若需客户端内自动化，仍走 UI。

### 1.2 行情/业务内核
- **Hevo 系（13 DLL）**：行情内核（`Hevo.Core/Api.Quotes/Sdk/UI/Widgets/MqApi`）——`QuoteRecvTimeout/QuoteSendTimeout/sid/MarketCode/udns/supercalc/calc/stats`（私有行情协议，加密）
- **Flight 系（9 DLL）**：业务/交易（`Flight.TradeCenter/TradeCore/Sdk/Quote/BusinessModule`）——交易消息模板 `委托失败 原因：{0}`/`撤单失败 原因：`/`交易连接被断开`
- **脚本**：IronPython（4）+ NLua/KeraLua（Lua 脚本）+ `ConditionCppWrap`（条件单 C++ 封装）
- **前端**：WPF + CefSharp 109（Chromium 内嵌网页）

### 1.3 网络/加密/工具
- NetMQ / AsyncIO（消息队列）、NaCl / BouncyCastle / SSPXEncode64（加密）、ZstdSharp / SharpCompress（压缩）、HtmlAgilityPack（HTML解析）、EntityFramework（ORM）

## 2. 网络通信轮廓（实测 netstat）

| 目标 | 端口 | 用途（推断） |
|---|---|---|
| hevo-h.10jqka.com.cn | 9601 | Hevo 行情（QuoteV2） |
| hevo.10jqka.com.cn | 8602 | Hevo 行情（QuoteV3 calc/stats/supercalc） |
| 多IP | 9602-9606 | wdcs/otqs 等业务服务 |
| 101.132.x.x | 8601 | GMS推送/udns |
| 127.0.0.1 | 63601-63619 | **本地 IPC**（happ ↔ 子进程/插件/守护） |
| 127.0.0.1 | 5051/5052 | 守护进程/内部服务 |

> ⚠️ 结论：**外部行情协议（Hevo）加密且私有，不建议逆向**（合规风险高、收益低）；本地 IPC（63601+）是 happ 内部通信，同样私有。**自动化主通道 = UI 层（已验证）+ 本地文件（本节数据资产）**。

## 3. 离线可读数据资产（自动化金矿，全部实测）

### 3.1 主力合约字典（新增，重宝）
- **位置**：`bin\data\FuturesDataBackup.db` → `FuturesData` 表 → `MAINCONTRACT` 字段
- **内容**：JSON `{code:0, data:{result:[{contractCode:"ad2611", market:"65"}, ...]}}`
- **覆盖**：87 个品种主力合约（上期所25/大商所23/郑商所26/其他8/UGFF 5）
- **用途**：策略自动选主力合约（知道每个品种当前交易的主力月份）
- ✅ 已导出：`探索记录\ths_market_data.json`

### 3.2 期权标的映射（新增）
- **位置**：同库 `OPTION` 字段
- **内容**：80 个期权标的（50ETF/300ETF/沪深300 IO/橡胶 ru/沪金 au/沪铜 cu... + 市场码 + 是否期货 + 期货代码）
- **用途**：期权策略的标的↔期权映射表（从标的名找期权品种代码）
- ✅ 已导出：同上 JSON

### 3.3 完整合约字典
- `bin\data\code\code.db` → `Contracts` 38966 行（Code/Name/DisplayCode/ExprieDate/OptionSide/ExecutePrice/TradeAmount乘数/MarketCode）
- 含 商品+金融期货 + 期权T型链 + 外盘 + 连续/主连合约

### 3.4 条件单本地库（新增）
- `bin\users\<账号>\multi\condi\condition.db` → `CondiOrder` 表（ParentOrderID/GroupID/ConditionOrder/ChildOrderIDs/Available/ModifyTime/AddTime）
- **用途**：条件单创建后可读本地状态（云端单据的本地镜像）

### 3.5 结算库
- `bin\users\AccountAnalyze\Settlement.db` → 6 表（Asset/PositionDetail/TradeDetail/ClosePosition/AccountNew/BankFuturesSerial）
- **用途**：历史资产/持仓/成交/平仓/银期，离线对账

## 4. 运行机制（日志/守护/更新）

- **启动链路**：hexinlauncher.exe → 检查更新(updater) → 启动 hdp 守护(hxdaemonprocess) → happ.exe 主程序
- **守护进程 hdp**：GMS push（可**远程推客户端命令 client_command**/日志检索/日志级别）、心跳上报、bugreport
- **更新机制**：Updateworking\updater.exe + update.log（复制launcher到Updateworking后自更新）
- **日志体系**：Log\Launch\launcher.log（启动）、debug.log（Cef控制台）、hxperformance\Log\（性能）、hdp 守护日志

## 5. 对自动化项目的技术选型总结

| 需求 | 推荐方案 | 依据 |
|---|---|---|
| 读取账户（资金/持仓/成交/委托） | **UI (UIA)** + Settlement.db 离线对账 | UI 实时 + 结算库历史 |
| 读取行情（盘口/五档/K线） | **UI (UIA盘口可读)** + 行情FieldGrid走剪贴板/OCR | Hevo加密不可直接复用 |
| 选品种/主力合约 | **FuturesDataBackup.db 主力字典 + code.db** | 离线免费 |
| 期权映射 | **FuturesDataBackup.db OPTION 字段** | 离线免费 |
| 条件单状态 | **condition.db 本地库** + UI | 双通道 |
| 下单 | **UI（ValuePattern+坐标+弹窗处理）** | 已全链路验证 |
| 直连券商CTP（可选升级） | vnpy_ctp（需券商开放CTP地址） | 软件底层即CTP协议 |
| 注意事项 | ① 行情协议加密勿逆向 ② GMS可远程推命令（安全注意） ③ 输入前清空品种框 ④ 交易时段/资金风控 | 全部实测 |
