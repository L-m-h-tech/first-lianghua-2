- 顶部功能 tab：`自选板块 / 多品种同列 / 板块同列 / 最近浏览`（另有 0 坐标 tab：`Product.FuturePro.QuotationPage`、`Product.FuturePro.FavouritePage` = 内部页面枚举名，说明行情页/自选页是不同 Product 页）。

  - 数值面板列（从上到下）：时间/最新/涨跌/涨跌幅/均价/持仓/现增仓(或日增仓/日增仓%)/成交量/成交额/开/收/今结/振幅/最高/最低。

## 3. 本地文件系统（关键发现）

### 3.1 安装目录 `E:\同花顺期货通\bin`
- 组件 DLL 观察确认架构：
  - **Hevo 系**：`Hevo.Api.Quotes.dll / Hevo.BusinessModule / Hevo.Core / Hevo.DataVisualization / Hevo.Interface / Hevo.Sdk / Hevo.UI / Hevo.Widgets / Hevo.MqApi / Hevo.CompositeControl / Hevo.Util` —— 行情/界面私有协议
  - **Flight 系**：`Flight.Quote / Flight.TradeCenter / Flight.TradeCore / Flight.BusinessModule / Flight.Product / Flight.Sdk` —— 行情/交易业务模块
  - **CefSharp 系**：`CefSharp.Wpf/CefSharp.Core/CefSharp.BrowserSubprocess.exe` —— 内嵌浏览器
  - **CTP/交易**：`Ctp.Core.dll / KSTradeAPI.dll / KSMarketDataAPI.dll / XOneWrap.dll / Femas.dll / gateway_sdk.dll` 等
  - **IronPython / NLua**：脚本支持组件
- `channel_info.xml`：`<hevo><channel qsid="8019"/></hevo>` —— Hevo 通道 QSID 配置
- `debug.log`：运行日志
- `FutureData\Notice.xml`（**UTF-16 LE**）：最近登录列表 + 券商公告列表
  - 最近登录账号：1813411165(20260421)、20511797(20260413)、8118038291(20260807)
  - 券商公告：华泰期货_CTP主席(3条)、银河期货_CTP(主席)(7条)，Content 为 HTML 转义文本
- `data\code\code.db`（**SQLite，38900 行 Contracts 表**）—— 同花顺本地合约字典（见 §4）
- `data\public\block_tree.xml`：板块树（`<block_tree DisplayName="自定义分类"><block_tree DisplayName="期货"><block_tree DisplayName="沪铝板块"><SecurityCode SecuritieCodes="1(65):al*,"/>`；65=SH 交易所枚举，67=??? 需对照）
- `data\public\DataPushJob.xml`：数据推送任务配置
- `dat\`：券商行情服务 dat 文件（`(20180425)ZLQH-ZLQHSHKY-0000_3rd.dat` 等，中州期货/大地/中大/利众/国元等）
- `Log\Launch\launcher.log`、`Updateworking`、`SreConfig` 等

### 3.2 code.db 合约字典（重要离线数据源）
- 表：`Contracts`（**38900 行**）
- 列：`Code, Name, Pinyin, MarketNumber, MarketCode, DisplayCode, ExprieDate, Subject, Limits, TradeCode, VarietyCode, OptionSide, ExecutePrice, TradeAmount, AllPinyin`
- 内容样例：
  - 主连/连号：`br9999` 合成橡胶主连 / `brzl1` 合成橡胶主连(成交量) / `brzl2` (持仓量) / `br05..br06` 连号；`SH2ZM1` 烧碱次主连(成交量)/`SHZM` 烧碱次主连
  - 期权合约：`CO4CY` 中证1000 2609购7600 → DisplayCode `MO2609-C-7600`，OptionSide=1，ExecutePrice=`7600.0000`
  - MarketCode 枚举：UCFD/UCFI/UCFL/UCFS/UCFT/UCFX/UCFZ/UCMC/UCMN/UCMS/UCOI/UCTF/UCVI/UCXF/UDEF/UDFM/UDLO/UFII/UFXB/UFXC...
- **用途**：离线查询品种代码→合约代码→期权执行价映射，做采集的品种字典（与 Legend instrument-cache 互补）。

## 4. 行情数据可获取性（对采集装置的意义）

1. **UIA 直读**：FieldGrid 自绘网格不暴露行情数字（实测确认）→ 直读不可行。
2. **剪贴板**（easytrader 验证过的同花顺系通用法）：聚焦网格 + ^A^C 复制 → 制表符解析（`parse_tsv`）。本项目 ths_ui_collector 采用此法。
3. **OCR**：截图自绘网格 → RapidOCR 表格还原（按表头行对齐列）。实测同花顺可整窗口截图。
4. **Notice.xml**：UTF-16 公告（券商公告）→ 已对接量化侧 news 表（ths_notice）。
5. **code.db**：离线合约字典 → 可做品种/期权代码解析补充。
6. **Hevo 私有协议**：加密，未深入逆向（合规风险高，不推荐）。
7. **CefSharp remote debugging**：官方支持 `--remote-debugging-port`，但行情网格是原生渲染不在 DOM；且 CefSharp v126 有调试端口回归问题；当前实例未带调试口。

## 5. 学会使用的操作要点（人机操作）

1. **启动**：双击 happ.exe（或桌面图标）。当前已启动未登录；**行情浏览无需登录**。
2. **看行情**：默认自选板块行情列表；分类 tab（全部/农副/黑色/农副期权/黑色期权/广期所…）切换品种组；点行→右侧联动 K线/数值面板。
3. **多品种同列**：顶部 tab 切换为上下/左右分屏显示多品种图。
4. **板块同列**：同板块品种同屏对比（实测显示"焦煤2701 jm2701"日线 + ETF/板块标签）。
5. **最近浏览**：历史查看过的品种。
6. **搜索**：右上放大镜（实测点击未弹输入，可能需先在别处唤起全局搜索或点击输入区）。
7. **板块管理**：右上按钮管理自选板块。
8. **交易**：右下"期货户/股票户"按钮进入登录/交易（当前未登录）。登录过华泰/银河 CTP 期货账户。
9. **底部状态栏**：沪指/同花顺商品/期货通商品三个指数（沪深300 沪指 + 全商品 + 期货通商品）。
