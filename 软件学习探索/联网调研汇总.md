## 一、OpenVlab Legend 调研结论

### 1. 软件定位与官方资料
- OpenVlab = 专业期权研究与波动率分析平台；Legend = Windows 桌面终端（当前安装 0.0.82，线上最新 0.0.98）。
- 官网 https://www.openvlab.cn ；下载页 /legend ；教学中心 /teaching （视频教程+FAQ，无 API 文档）。
- GitHub：`Tradersway/openvLab`（网页版前端重制，15★，非官方）；组织 `github.com/openvlab` 存在但 0 公开仓库；无任何采集/自动化项目。
- **无公开开发者/API 文档**（/docs /api-doc /swagger 全 404）。

### 2. 账号与登录
- 官方仅公开 SimNow 模拟 + 实盘（套餐：经典版 0 元低频 / Pro 0 元需合作机构 / 机构版 1 万元起高频直连柜台；合作机构华金期货）。
- openctp 无官方支持声明（仅创始人参加过 openctp 社区"大咖说"直播）。
- 本地 cfwtd 网关协议（site.list/user.login/md.subscribe/token）**全网无任何公开讨论**（cfwtd 唯一命中是减肥指南）。

### 3. API 实测结论（重要）
- 匿名可用（返回 `{"code":0,...,"message":"ok"}`）：
  - `GET /api/ctamap-all`：**76 品种全期权波动率地图**
  - `GET /api/dto/{code}`：**单标的行情**（最新/买卖/量仓 + 多周期收益率）—— code 支持品种代码（SA/MA）与 ETF（510050）
  - `GET /api/volatility-surface/{code}`：**按月波动率曲面**（mktvol/atmv/forward/delta/希腊字母/PCR 持仓/pdf_list 等）
- 需登录态（匿名 404）：`/api/volatility-surface-yday/{code}`、`/api/watchlist/*`（鉴权失败统一 404 隐藏存在性）。
- 额外：`https://api.openvlab.cn` 是 MCP 服务器（`mcp_auth_invalid`，需软件内 token，公开渠道无颁发页面）。

### 4. 社区内容
- B 站"OpenVlab期权软件基础使用教程"（实时行情/波动率曲面/策略构建/期权异动）https://www.bilibili.com/cheese/play/ep1748162
- 百度开发者"波动率分析工具Openvlab实战" https://developer.baidu.com/article/detail.html?id=5822958

### 5. 给本项目的落点
- **openvlab REST 三端点可做免费权威补充数据源**（期权曲面/希腊字母/波动率地图），绕开界面操作。
- cfwtd 协议无现成资料，只能抓包/逆向（本项目已做部分）。

## 二、同花顺期货通调研结论

### 1. 软件定位与官方下载
- 同花顺期货通 = 行情/交易/资讯一体化期货终端；官方下载：https://fupage.10jqka.com.cn/futures-projects/operation/pc-download/index.html ／ https://download.10jqka.com.cn/free/thsqht/

- 无对 FutureData/Notice.xml、code.db、Hevo 协议的公开分析文章（Bing/CSDN 均被本地法律过滤 + grep.app 429）。

### 3. 自绘网格采集的业界验证做法
- **easytrader 即完整先例**：pywinauto 窗口自动化 + 剪贴板复制 + 刷新按钮；验证码场景用截图+OCR（issue #461 Tesseract 验证码）。
- 剪贴板被限的绕法：右键复制、换老版本客户端（issue #448/#452/#272）。
- 结论：**剪贴板 + OCR 是自绘网格的最稳路线**（本项目同花顺即采用该三级策略）。

### 4. CefSharp remote debugging
- 标准做法：`CefSettings.RemoteDebuggingPort = <端口>` 或 `--remote-debugging-port=<端口>`，访问 `localhost:<端口>/json` 走 CDP。
- 坑：CefSharp v126 起该端口回归失效（issue #4894，无 workaround）；Chrome Runtime 模式无法调试（#4919）。
- 注意：行情自绘网格是原生渲染，**不会出现在 CefSharp 页面 DOM** → CDP 对本软件行情采集帮助有限。

## 三、调研结论对采集装置的整体启示

1. **数据源补充**：openvlab 匿名 REST（ctamap-all/dto/volatility-surface）可作为 Legend/同花顺界面采集之外的第 3 路免费权威数据源（尤其期权曲面/希腊字母，正好补 T 型报价空链的短板）。
2. **方法验证**：同花顺自绘网格走"剪贴板+OCR"（easytrader 系验证过）与本项目已实施策略一致，方向正确。
3. **没有可抄的现成代码**：Legend 与期货通的自动化均无现成公开项目，本项目已是"从零逆向第一人"，当前实现路径（CDP+UIA+OCR+文件源）就是社区最优解的组合。
4. **风险提示**：同花顺登录逆向有"登录多了会风控"教训；不建议深挖 Hevo 加密协议（合规/反制风险）；一切采集保持低频、个人研究用途。
